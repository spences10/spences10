## Selected Open Source

### Coding Agents and Developer Tooling

- 🤖 **[my-pi](https://github.com/spences10/my-pi)** — composable Pi coding agent with MCP, LSP, agent chains, prompt presets, and local eval telemetry.
- 🔄 **[pirecall](https://github.com/spences10/pirecall)** — syncs Pi coding-agent sessions to SQLite for search, recall, and analytics.
- 🔐 **[nopeek](https://github.com/spences10/nopeek)** — reduces accidental secret disclosure in LLM coding sessions.
- 🧰 **[mcpick](https://github.com/spences10/mcpick)** — vendor-neutral CLI for adding, toggling, and auditing MCP servers and agent skills across AI clients.
- ✅ **[check-skills](https://github.com/spences10/check-skills)** — vendor-neutral validation for portable Agent Skills.

### Model Context Protocol

- 🔍 **[mcp-omnisearch](https://github.com/spences10/mcp-omnisearch)** — unified web search, AI answers, and content extraction across Tavily, Brave, Kagi, Exa, Firecrawl, and Linkup.
- 🧠 **[mcp-sequentialthinking-tools](https://github.com/spences10/mcp-sequentialthinking-tools)** — structured reasoning that recommends the most effective MCP tools at each stage of a task.
- 🗃️ **[mcp-sqlite-tools](https://github.com/spences10/mcp-sqlite-tools)** — safety-gated SQLite operations for AI assistants, with clear read-only and destructive boundaries.
- 📚 **[mcp-svelte-docs](https://github.com/spences10/mcp-svelte-docs)** — searchable access to Svelte documentation with built-in caching.
- 🧩 **[mcp-memory-libsql](https://github.com/spences10/mcp-memory-libsql)** — persistent semantic memory and knowledge graphs for AI agents using libSQL.

### Svelte and SvelteKit

- 🧪 **[Sveltest](https://sveltest.dev)** — Svelte 5 testing examples and patterns for Vitest Browser Mode, Playwright, and `vitest-browser-svelte`.
- 🦀 **[svelte-skills-kit](https://github.com/spences10/svelte-skills-kit)** — reusable Agent Skills for building with Svelte and SvelteKit.
- 📺 **[sveltekit-embed](https://github.com/spences10/sveltekit-embed)** — SvelteKit components for embedding YouTube, Spotify, CodePen, and other media.
- 🍺 **[Svead](https://github.com/spences10/svead)** — Svelte SEO component for metadata, canonical URLs, Open Graph tags, and Schema.org structured data.
